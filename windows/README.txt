X Space 다시듣기 저장 (XSpaceSaver)

master_playlist.m3u8 URL로 X Space 녹음을 m4a 파일로 저장하는 프로그램.
Windows 10/11 전용. Python 설치 필요 없음.

[사용 방법]
1. 압축을 풀고 XSpaceSaver.bat 더블클릭
2. 주의사항 5개 모두 체크
3. "ffmpeg: 없음"이면 [ffmpeg 설치] 클릭 -> 새 창이 닫힐 때까지 대기 (최초 1회)
4. master URL 붙여넣기 -> [저장 시작]
5. 완료 후 [저장 위치 열기]로 파일 확인

[문제 해결]
- "Windows의 PC 보호" 또는 보안 경고가 뜨는 경우: 파일 출처를 확인한 뒤 "추가 정보" -> "실행"
- 창이 뜨지 않고 검은 창에 에러가 남는 경우: 그 화면을 캡처해서 전달
- ffmpeg 설치 버튼이 동작하지 않는 경우: Microsoft Store에서 "앱 설치 관리자" 설치 후 재시도,
  또는 ffmpeg.exe를 이 폴더에 직접 넣으면 그대로 사용함
- "조각 파일 경로를 찾지 못했습니다": 녹음 삭제, 비공개 전환, 또는 진행 중인 Space

[주의]
- 다시 듣기가 켜진, 끝난 Space만 저장 가능
- 녹음 저작권은 호스트와 발언자에게 있음. 개인 보관용으로만 사용
- master URL에는 방송 접근 키가 포함됨. 공유·공개 금지
- X 구조 변경 시 동작하지 않을 수 있음
